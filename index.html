FAQ

Questions.

Do I need to own Minecraft?

Yes. BYTEZ requires a valid Minecraft license and official Microsoft authentication. It is not a cracked launcher.

Which versions are supported?

BYTEZ is designed for fully released versions from 1.0 to the latest official release. Snapshots are not supported.

Does a hosted world stay online?

Only while its owner is online and hosting. It is not a 24/7 server.

How much is BYTEZ+?

€2.50 per month. The main client is intended to be available separately from the optional subscription.

Is BYTEZ affiliated with Mojang or Microsoft?

No. BYTEZ is an independent third-party client.
